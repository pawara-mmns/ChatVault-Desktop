# Synthetic native reader vectors

Generated by `scripts/generate-native-fixtures.mjs` using Node SQLite, OpenSSL AES-256-GCM with a 16-byte nonce, HKDF-SHA256 and zlib. RustCrypto decrypts these independent vectors in tests.

All identifiers, messages and image bytes are synthetic. The public test root/AES key is 32 bytes of `0x07`. `synthetic-key14.bin` is an intentionally public 131-byte test key structure, not a private key from any device. These files are compiled only in tests and never seed production archives.

The vectors cover crypt14/messages and crypt15/message-chat-jid families. Their generated contents may be used and regenerated as project test data. No third-party encrypted backup or personal conversation is included.
